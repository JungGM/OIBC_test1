# OIBC test1 — 2024년 로컬 백테스트

2022~2023년 제공 데이터로 모델을 학습하고 2024년 예측을 만든 실험이다. XGBoost와 두 그룹의 선택 과정, LightGBM 기준과의 비교, 결측으로 인한 채점 한계는 [2024 테스트 보고서](TEST1_2024_REPORT.md)에 설명한다.

2024년 전체 8,784시간 예측을 생성했지만 253개 발전소 실적이 모두 있는 178시간만 대회식으로 채점할 수 있다. 그 시간의 벌금은 기준 대비 8.65% 감소했다. 이는 연간 전체 또는 공식 점수가 아니다.

- [설계와 논문 적용 범위](BACKTEST_METHOD.md)
- [공식 규정 확인 기록](OFFICIAL_RULES_CHECK_20261029.md)
- `backtest.py`: 학습, 그룹 탐색 및 채점
- `export_test_2024.py`: 로컬 2024년 테스트용 CSV 생성 및 구조 점검
- `verify_backtest_results.py`: 독립 정산 재계산과 실행 검증
- `validate_submission.py`: 공식 제출 기간 CSV 구조 점검

원본 자료, 학습 모델 및 발전소별 예측·테스트 CSV는 공개 저장소에 포함하지 않는다. 테스트 파일은 공식 제출 기간과 다르다. 실행 명령과 파일 위치는 보고서를 참조한다.
